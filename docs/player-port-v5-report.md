# 播放器选项移植：v5 测试版

目标为官方粉版哔哩哔哩 8.27.0（8270400），模块版本 `1.23.3-lsposed.5`，要求 Modern LSPosed API 102。播放器目录除下述暂缓项外已接入运行逻辑和设置控件。共 45 项配置接入代码，其中本轮新增 29 项；这表示已实现并通过本地检查，不表示真机验证通过。

## 本轮范围

| 功能 | 实现与范围 |
| --- | --- |
| 半屏、Wi-Fi 全屏、移动网络全屏画质 | 适配配置入口、默认画质和新版 PlayViewUnite 响应；调整播放请求的画质能力参数；实际流以服务器返回为准 |
| 新旧播放器 | 接入对应 AB 配置及旧播放列表路由；必须重启宿主并重新进入视频 |
| 默认倍速、记忆倍速、长按倍速 | 分开处理初始化速度、用户选择和临时长按速度，避免把长按速度记成默认速度 |
| 自定义倍速列表 | 适配新旧菜单、竖屏 Story、播客和内联播放的数组或列表入口；支持最多 64 个不重复正数，必须包含 1 倍速；重启生效 |
| 禁用长按、双指切换比例 | 拦截长按入口；收缩适应内容、放大居中裁剪；隐藏还原缩放控件 |
| 记忆无损音质 | 从播放配置编辑请求记录开关，应用于旧版 PlayConf 和新版设备配置；不授予音质权限 |
| 禁止自动连播、禁止常驻分段章节 | 修改相应播放响应；只覆盖原选项对应的数据入口 |
| 禁用 P2P 上传、优先稳定 CDN | 调整相关配置，播放分段构建后从现有备用地址中选择；直播地址不做 CDN 替换 |
| 强制硬解 | 在宿主设置播放器参数期间临时启用硬解开关，随后还原配置对象 |
| 主站 AccessKey | 用户手动填写，限定用于主站 PlayViewUnite HTTPS 接口；输入框遮掩内容、不启用自动填充；日志不输出密钥 |
| VIP 画质试看 | 仅已知非 VIP 账号处理服务器已返回的 DASH 流，并调整试看标记；不是会员权限解锁，时长及画质由服务器限制 |
| 自动选择现有 AI 字幕 | 无普通简中文字幕时调整现有 ai-zh 轨道的选择信息，不调用翻译服务 |
| 字幕样式 | 背景、粗体、横竖屏字号、填充和描边颜色、描边宽度、底部偏移；支持选择 TTF/OTF 字体和恢复默认字体 |
| 字幕导入保存 | 宿主字幕面板增加按钮；导入 UTF-8 ASS、SRT、VTT、BCC JSON；通过系统文件选择器保存 ZIP，内含各轨道 JSON 和 SRT |

## 暂缓及差异

- 按用户最新要求，自动翻译本轮不适配。原“自动生成字幕”开关和“字幕翻译服务”设置标为未移植、不可编辑，模块中不包含翻译服务调用。该开关原来还包含繁简转换，本轮一并暂缓。
- 泰区 AccessKey 仍未移植，依赖尚未接入的泰区播放链路。主站 AccessKey 可编辑。
- 字幕导出使用用户选择位置的 ZIP，并不自动写入 Downloads 散文件。导入内容保存在当前宿主进程内，重启后需重新导入；最多缓存 8 个视频，每个视频最多 16 份导入字幕。字体另存于宿主私有目录，重启可保留。
- 新版长按提示中的倍速文字、超过原上限的自定义倍速高亮、Story/播客/商城分支及横竖屏样式需要真机核验。手势提示和震动未完整复刻原版。
- 自定义字幕样式采用 Android 原生布局和绘制，不宣称与原版所有字体、双语排版效果一致。

## 建议真机验证顺序

1. 覆盖安装 v5，保持 LSPosed 作用域为官方 8.27.0，彻底结束并重新打开哔哩哔哩。
2. 先检查已有设置、底栏和净化功能，然后逐项开启默认倍速、记忆倍速、长按速度和自定义列表；确认退出长按后恢复原速度。
3. 分别测试 Wi-Fi/移动网络、横竖屏、新旧播放器及下一个视频；检查画质、无损开关和自动连播。
4. 用短 UTF-8 SRT 导入，切换字幕并导出 ZIP；再检查字体、颜色、字号和偏移。
5. 不稳定选项最后单独测试；异常时提供对应操作和模块日志，避免一次开启所有选项而无法定位。

所有设置仍保存在宿主 SharedPreferences。清除宿主数据会清除设置和字体；模块沿用此前本机测试证书，可覆盖安装。GPL-3.0 及原仓库来源保持不变。
